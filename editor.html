कोड तयार छ

तलको सबै कोड कपी गरेर GitHub मा टाँस्नुहोस्।

GitHub मा कसरी हाल्ने

  1. आफ्नो repository खोल्नुहोस् → data.js फाइलमा थिच्नुहोस्
  2. दायाँ माथिको पेन्सिल (✏️) चिन्हमा थिच्नुहोस्
  3. भित्रको सबै पुरानो कोड मेट्नुहोस् (Ctrl+A वा सबै छानेर Delete)
  4. माथि कपी गरेको नयाँ कोड टाँस्नुहोस् (Paste)
  5. तल हरियो Commit changes थिच्नुहोस्
  6. १ मिनेटपछि वेबसाइट refresh गर्नुहोस् — अपडेट भइसक्यो ✅
कोड डाउनलोड गर्नुभयो भने: GitHub मा Add file → Upload files गरेर पुरानो data.js माथि नयाँ चढाए पनि हुन्छ।
